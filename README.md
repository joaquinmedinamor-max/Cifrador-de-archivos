# CipherGuard Pro

CipherGuard Pro es una aplicación de escritorio desarrollada en Python para el cifrado y descifrado de archivos, garantizando la confidencialidad e integridad de la información mediante algoritmos de criptografía simétrica.

## Características principales
- **Criptografía Robusta:** Utiliza `Fernet` (basado en AES) para asegurar que tus datos sean inaccesibles sin la llave correcta.
- **Interfaz Moderna:** Desarrollado con `CustomTkinter` para una experiencia de usuario fluida y profesional.
- **Procesamiento en Segundo Plano:** Implementación de `threading` para evitar bloqueos de la interfaz durante procesos pesados.
- **Integridad de Datos:** Protección automática contra archivos alterados o corruptos.

## Tecnologías utilizadas
- **Python 3.x**
- **CustomTkinter:** Interfaz gráfica moderna.
- **Cryptography:** Manejo de cifrado y seguridad.
